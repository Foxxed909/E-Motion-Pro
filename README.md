# E-Motion Pro

A cinematic showcase library of **animations, transitions and motion graphics** for apps and websites, plus **30 original typefaces** generated by its own font engine.

- **51 live pieces** across **13 genres**: kinetic type, page transitions, micro-interactions, app UI, scroll stories, shaders, particles & physics, 3D & depth, loaders, retro & glitch, data in motion, organic & liquid, and editorial.
- **30 new fonts** (OTF + WOFF2, SIL OFL 1.1), all drawn from one hand-built letter skeleton and rendered by code.
- **No stock images.** Everything on screen is computed: DOM and SVG motion, Canvas 2D, and raw WebGL shaders.

## Features

- **Live source** on every piece page, highlighted at build time with Shiki, plus a copy button.
- **⌘K command palette** (or `/`) that searches pieces, fonts, genres and pages, with a live preview.
- **Sound design** made entirely with Web Audio: hover ticks, click plucks, route whooshes and an ambient pad. It is off by default and the preference is remembered.
- **Keyboard:** `R` replays, `F` goes fullscreen and `←` / `→` move between pieces.
- **Social images** for every route, generated at build time in the site's own fonts.
- **SEO and PWA basics:** sitemap, robots, web manifest and icons.
- **Vercel Analytics and Speed Insights**, which only become active once deployed on Vercel.

## Stack

Next.js 16 (App Router, fully static) · React 19 · TypeScript · Tailwind CSS v4 · Motion · Lenis · raw WebGL · Web Audio · Shiki · next/og · Vercel Analytics

## Develop

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build (static)
npm run fonts      # regenerate the 30 fonts + src/app/fonts.css + src/data/fonts.json
```

## Deploy to Vercel

Import the repository in Vercel. The framework is detected as Next.js and no environment variables are needed. Every route is prerendered at build time.

## Project map

| Path | What |
|---|---|
| `src/app/` | Routes: `/` landing, `/gallery`, `/motion/[slug]`, `/fonts` |
| `src/components/landing/` | Landing sections: preloader, shader hero, velocity band, manifesto, featured reel, genre index, type showcase, stats |
| `src/demos/registry.ts` | Metadata for every piece and genre |
| `src/demos/pieces/*.tsx` | One file per motion piece (lazy-loaded) |
| `src/demos/Stage.tsx` | Size container every piece renders into; pieces scale with `cqw`/`cqh` |
| `src/components/ShaderCanvas.tsx` | Minimal WebGL runner (pointer, hover, custom uniforms, pause when off-screen) |
| `scripts/fonts/` | The font engine: `skeleton.mjs` (letterforms), `geom.mjs` (geometry kernel), `styles.mjs` (30 renderers), `build.mjs` |

### Adding a piece

1. Create `src/demos/pieces/my-piece.tsx` with a default export `({ mini }: DemoProps) => JSX` that fills its parent (`absolute inset-0`).
2. Add an entry to `DEMOS` in `src/demos/registry.ts`.
3. Add it to `PIECES` in `src/demos/components.tsx`.

`mini` is true in gallery thumbnails, where pieces should self-animate instead of waiting for the pointer.

## The font engine

Each glyph is a set of centre-line polylines (cap height 700 units). A style turns those lines into filled contours in one of these ways:
monoline offsetting (caps and joins), hatching, zig-zag wires, hollow rings with true counters, stacked wireframe extrusion, crooked mosaic tiles, broad-nib Minkowski sweeps, dot and dash resampling, pixel/LED/cross-stitch rasterisation, scanline and barcode runs, parallel multiline offsets, neon tube outlines, stencil cuts, glitch and slat band clipping, jittered pencil passes, and variable-width ribbons and brushes. Contours are wound consistently so overlaps union under non-zero fill, then written as CFF OpenType with `opentype.js` and compressed to WOFF2.

## Accessibility

Respects `prefers-reduced-motion` (no preloader, smooth scroll off, CSS animations collapsed, Motion animations reduced, shaders slowed). The custom cursor only runs on fine pointers.
